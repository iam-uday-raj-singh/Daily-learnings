# Daily Learnings

A structured record of my continuous learning and implementation in Python, Machine Learning, and SQL.

This repository is focused on building practical understanding through consistent implementation rather than simply collecting notes.

## Repository Structure

### Python-DSA
Daily problem-solving practice in Python, organized by data structure and algorithmic concept.

### Python-for-ML
Practical implementation and experimentation with Python libraries commonly used in machine learning and data analysis.

### ML-Concepts
Implementation-focused exploration of machine learning concepts, algorithms, evaluation techniques, and underlying intuition.

### SQL
Weekly SQL practice covering analytical querying, data manipulation, and concepts relevant to data science and machine learning workflows.

## Learning Philosophy

For each topic, I aim to understand:

- What the concept does
- Why it works
- When it should be used
- Its limitations and failure modes
- How to implement it
- How to evaluate the result

The objective is to gradually move from learning individual concepts to building reliable end-to-end ML systems.
